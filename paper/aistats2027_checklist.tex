% AISTATS 2027 reproducibility checklist.
% Questions preserve the AISTATS 2027 sample-paper wording; answers and justifications are evidence-bounded.
\section*{Checklist}
\begin{enumerate}[leftmargin=*]
\item For all models and algorithms presented, check if you include:
  \begin{enumerate}
    \item A clear description of the mathematical setting, assumptions, algorithm, and/or model. [Yes] The Method and Experimental Setup sections specify the serialized ARC input, encoder, quantizer, memory, planner, target path, objective, comparator, and frozen protocol.
    \item An analysis of the properties and complexity (time, space, sample size) of any algorithm. [Yes] The Computational and storage complexity subsection gives source-bounded time, storage, activation, and frozen-budget bounds for the executed ARC path.
    \item (Optional) Anonymized source code, with specification of all dependencies, including external libraries. [Yes] The deterministic anonymous supplement contains the frozen scientific source snapshot, the declared Python dependencies, and the main ARC runners/verifiers. CI rejects author/repository/submission identifiers and verifies the extracted source compiles. Exact resolved historical package versions beyond the retained Python 3.11/CPU boundary are not reconstructed.
  \end{enumerate}
\item For any theoretical claim, check if you include:
  \begin{enumerate}
    \item Statements of the full set of assumptions of all theoretical results. [Not Applicable]
    \item Complete proofs of all theoretical results. [Not Applicable]
    \item Clear explanations of any assumptions. [Not Applicable] The paper reports an empirical falsification study rather than new theoretical results.
  \end{enumerate}
\item For all figures and tables that present empirical results, check if you include:
  \begin{enumerate}
    \item The code, data, and instructions needed to reproduce the main experimental results (either in the supplemental material or as a URL). [Yes] The deterministic anonymous supplement contains the frozen source snapshot, ARC protocol and checksum manifest, a train/validation-only official-data downloader, exact five-seed reproduction commands, verification scripts, and expected aggregate results. It does not redistribute the third-party ARC corpus or expose the locked test split.
    \item All the training details (e.g., data splits, hyperparameters, how they were chosen). [Yes] The paper gives retained train/validation sizes, five fixed seeds, epochs, batch size, learning rate, model steps, device class, and the pinned pretrained checkpoint, together with frozen objective and decision gates.
    \item A clear definition of the specific measure or statistics and error bars (e.g., with respect to the random seed after running experiments multiple times). [Yes] The paper defines means, sample standard deviations, seed pairing, and retained paired bootstrap intervals.
    \item A description of the computing infrastructure used. (e.g., type of GPUs, internal cluster, or cloud provider). [No] CPU execution is retained, but exact physical CPU model metadata was not retained and is not reconstructed.
  \end{enumerate}
\item If you are using existing assets (e.g., code, data, models) or curating/releasing new assets, check if you include:
  \begin{enumerate}
    \item Citations of the creator If your work uses existing assets. [Yes] ARC-Challenge and the pinned DeBERTa-family comparator are cited.
    \item The license information of the assets, if applicable. [Yes] The ARC distribution used for this study is identified as CC BY-SA 4.0, and the pinned \texttt{microsoft/deberta-v3-xsmall} checkpoint is MIT-licensed.
    \item New assets either in the supplemental material or as a URL, if applicable. [No] The retained evidence/reproduction package is not yet released as an anonymous review artifact.
    \item Information about consent from data providers/curators. [Not Applicable] No new human-subject data were collected or curated.
    \item Discussion of sensible content if applicable, e.g., personally identifiable information or offensive content. [Not Applicable] The study uses a public multiple-choice science benchmark and introduces no sensitive human-subject data.
  \end{enumerate}
\item If you used crowdsourcing or conducted research with human subjects, check if you include:
  \begin{enumerate}
    \item The full text of instructions given to participants and screenshots. [Not Applicable]
    \item Descriptions of potential participant risks, with links to Institutional Review Board (IRB) approvals if applicable. [Not Applicable]
    \item The estimated hourly wage paid to participants and the total amount spent on participant compensation. [Not Applicable]
  \end{enumerate}
\end{enumerate}
