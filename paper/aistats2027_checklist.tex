\section*{Checklist}
\begin{enumerate}[leftmargin=*]
\item For all models and algorithms presented, check if you include:
  \begin{enumerate}
    \item A clear description of the mathematical setting, assumptions, algorithm, and/or model. \textbf{Yes.} The Method and Experimental Setup sections specify the serialized ARC input, encoder, quantizer, memory, planner, target path, objective, comparator, and frozen protocol.
    \item An analysis of the properties and complexity (time, space, sample size) of any algorithm. \textbf{No.} Experimental budgets and parameter counts are reported, but no formal complexity analysis is claimed.
    \item (Optional) Anonymized source code, with specification of all dependencies, including external libraries. \textbf{No.} Exact project-controlled reproduction instructions and dependencies exist, but an anonymous review bundle is still pending.
  \end{enumerate}
\item For any theoretical claim, check if you include:
  \begin{enumerate}
    \item Statements of the full set of assumptions of all theoretical results. \textbf{Not Applicable.}
    \item Complete proofs of all theoretical results. \textbf{Not Applicable.}
    \item Clear explanations of any assumptions. \textbf{Not Applicable.} The paper reports an empirical falsification study rather than new theoretical results.
  \end{enumerate}
\item For all figures and tables that present empirical results, check if you include:
  \begin{enumerate}
    \item The code, data, and instructions needed to reproduce the main experimental results (either in the supplemental material or as a URL). \textbf{No.} Exact commands, retained-artifact lineage, and verification procedures exist internally; the anonymous reproduction package is still pending.
    \item All the training details (e.g., data splits, hyperparameters, how they were chosen). \textbf{Yes.} The paper gives retained train/validation sizes, five fixed seeds, epochs, batch size, learning rate, model steps, device class, and the pinned pretrained checkpoint, together with frozen objective and decision gates.
    \item A clear definition of the specific measure or statistics and error bars (e.g., with respect to the random seed after running experiments multiple times). \textbf{Yes.} The paper defines means, sample standard deviations, seed pairing, and retained paired bootstrap intervals.
    \item A description of the computing infrastructure used. \textbf{No.} CPU execution is retained, but exact physical CPU model metadata was not retained and is not reconstructed.
  \end{enumerate}
\item If you are using existing assets (e.g., code, data, models) or curating/releasing new assets, check if you include:
  \begin{enumerate}
    \item Citations of the creator if your work uses existing assets. \textbf{Yes.} ARC-Challenge and the pinned DeBERTa-family comparator are cited.
    \item The license information of the assets, if applicable. \textbf{No.} Asset-license metadata has not yet been integrated into the anonymous manuscript package.
    \item New assets either in the supplemental material or as a URL, if applicable. \textbf{No.} The retained evidence/reproduction package is not yet released as an anonymous review artifact.
    \item Information about consent from data providers/curators. \textbf{Not Applicable.} No new human-subject data were collected or curated.
    \item Discussion of sensitive content if applicable, e.g., personally identifiable information or offensive content. \textbf{Not Applicable.} The study uses a public multiple-choice science benchmark and introduces no sensitive human-subject data.
  \end{enumerate}
\item If you used crowdsourcing or conducted research with human subjects, check if you include:
  \begin{enumerate}
    \item The full text of instructions given to participants and screenshots. \textbf{Not Applicable.}
    \item Descriptions of potential participant risks, with links to Institutional Review Board (IRB) approvals if applicable. \textbf{Not Applicable.}
    \item The estimated hourly wage paid to participants and the total amount spent on participant compensation. \textbf{Not Applicable.}
  \end{enumerate}
\end{enumerate}
